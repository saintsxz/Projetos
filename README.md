## 📊 Monitor de Preços com Python

Sistema automatizado que monitora preços de produtos no Mercado Livre utilizando Selenium.

### 🔧 Tecnologias utilizadas
- Python
- Selenium
- WebDriver Manager
- dotenv
- SMTP
- JSON

### ⚙️ Funcionalidades
- Captura automática de preços
- Histórico de preços em `.jsonl`
- Comparação de preços
- Alertas automáticos por e-mail
- Proteção de variáveis sensíveis com `.env`
- Anti-bot básico para navegação automatizada
